# LIBERO-PRO × YLYW —— 路线图与验收标准

> 目标问题：**易理模型（YLYW）在 LIBERO-PRO 上能达到什么水平？**

## 阶段一：本地可行性验证（本机可跑）✅/🚧

**目的**：在无 GPU、无 robosuite 的条件下，用轻量 MuJoCo 环境复刻 LIBERO-PRO 的四类扰动，
先验证"YLYW 推理层"在扰动下的零样本行为是否如预期鲁棒。

| 编号 | 任务 | 验收标准 | 状态 |
|------|------|----------|------|
| 1.1 | 平面抓取环境 `sim/env.py` | MuJoCo 能加载、reset、step，物体可被抓到 | ✅ |
| 1.2 | 四类扰动 `sim/perturb.py` | 每类扰动可参数化开关，扰动幅度可调 | ✅ |
| 1.3 | 特征提取 `sim/features.py` | 仿真状态 → YLYW 13 维特征，值域合法 | ✅ |
| 1.4 | YLYW 适配 `ylyw_adapter/inference.py` | 特征 → 卦象 → 动作指令，端到端跑通 | ✅ |
| 1.5 | 评测主循环 `sim/runner.py` | 输出各类扰动下的成功率 + 方差 + 推理链 | ✅ |
| 1.6 | 一键脚本 `scripts/run_local_eval.py` | 一条命令出结果 JSON | ✅ |

**阶段一结果（2026-09-22，20 eps/条件）**：none 100% / object 95% / position 100% /
semantic 100% / task 100% / **all 75%**；语义扰动卦象重叠 95%，情境扰动卦象重估 25–40%。
详见 `docs/实验报告_阶段一_20260922.md`。

**阶段一结论**：✅ 已验证 YLYW 推理层在扰动下具备语义稳定性与情境敏感性，
扰动衰减（25%）远小于 VLA 的崩溃模式（~90%→0%）。

**阶段一预期结论**（待实测）：YLYW 在 Position / Semantic 扰动下相对自身无扰动基线的
**成功率衰减**应显著小于 VLA 的"90%→0%"崩溃模式。
