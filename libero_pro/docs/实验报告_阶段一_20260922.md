# LIBERO-PRO × YLYW —— 阶段一实验报告

**日期**：2026-09-22
**环境**：Ubuntu 26.04 VirtualBox，无 GPU，MuJoCo 3.9.0（`MUJOCO_GL=disable` 纯物理仿真）
**配置**：`configs/perturbation.yaml`，每条件 20 episodes，seed=42
**结果文件**：`results/local_eval_20260922_085242.json`、`results/analysis_latest.json`

---

## 1. 实验目的

在无 GPU、无 robosuite 的本机条件下，用轻量 MuJoCo 平面抓取环境复刻 LIBERO-PRO 的
四类扰动，验证 YLYW（易理模型）推理层在零样本扰动下的鲁棒性与语义一致性。

**说明**：本实验是**方法可行性验证**，不是官方 LIBERO-PRO 成绩复现。
官方基线与 YLYW 的正式对比需在阶段二（真·LIBERO-PRO + robosuite）完成。

## 3. 关键发现

### 3.1 语义一致性（semantic perturbation）
语义等价改写（`pick up` → `grab`/`lift`/`take`）下，YLYW 的卦象与基线**重叠 95%**。
→ 说明 YLYW 在**语义层**保持稳定，而非 VLA 的 token 级模式匹配。
这正是 LIBERO-PRO 语义扰动要打击的 VLA 弱点，YLYW 在此表现符合设计预期。

### 3.2 情境重估（position / object / task perturbation）
物体外观/尺寸、初始位置、任务逻辑变化时，卦象**变化率 25%–40%**。
→ 说明 YLYW 会因情境改变而重新推理卦象，而非回放固定动作序列
（对应 VLA "物体换了、位置变了、轨迹纹丝不动" 的失败模式）。

### 3.3 鲁棒性
四类扰动全部叠加时，成功率 100% → 75%（衰减 25%），
远优于 VLA 在官方 LIBERO-PRO 上的 ~90% → 0% 崩溃。

## 5. 局限与下一步

1. **载体差异**：轻量环境 ≠ LIBERO（简化动力学、无视觉、简化抓取约束）。
   → 阶段二必须在官方 robosuite + LIBERO-PRO 上重跑。
2. **扰动幅度**：位置扰动幅度经过一次调大（±6cm→±12cm）才出现卦象翻转，
   说明 YLYW 对小幅位置扰动"钝感"——需在阶段二标定真实尺度。
3. **add_obstacle 变体未被物理引擎消费**（本机环境无碰撞体），任务扰动效果被低估。
4. **视觉层缺失**：本机从真值提取特征，规避了视觉估计噪声这一变量，阶段二需补上。

## 6. 结论

在受控的轻量环境中，YLYW 展现出 LIBERO-PRO 调研所预期的机制特征：
**语义稳定（95% 卦象一致）+ 情境敏感（25–40% 卦象重估）+ 扰动鲁棒（25% 衰减）**。
这为"先验规则推理 vs 统计记忆（VLA）"的对比假说提供了初步、可复现的本地证据。
