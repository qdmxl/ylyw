## 二、仍未跑通（诚实记录）

**最终"夹爪合拢抓住球"这一步未成功**，表现为：

- 夹爪下降到球心高度时，**物体被顶到桌面以上 ~34mm**（z≈0.802，正常应 0.768）。
  → 说明夹爪的某个 geom（finger box / gripper_mount）从**上方压到球**，而非从两侧夹住。
- 缓慢合拢夹爪过程中，两指到球心距离始终 ≥4cm（**未接触**），随后抬升时球被弹飞。
- 推测原因：指尖几何中心与实际接触点还有偏差；夹爪开合行程（±0.08）与球径（0.056）
  的匹配需要更精细的力控/阻抗控制，而非位置开关。

## 补充诊断（最终定位）

持续调试后，**精确定位了抓取失败的根本原因（是夹爪建模问题，非控制问题）**：

1. **`gripper_mount` 挡住球体落座**：夹爪中间有一个 box（`gripper_mount`, 0.01×0.01×0.015），
   在手指之间。下探时它与球顶碰撞（实测 dist=-0.0092），**把球顶住**，球无法落入两指之间。
2. **手指关节卡死/不对称**：闭合时 fl_j=0.085（超出 ±0.08 量程）、fr_j=0.058，
   两指**不同步且单侧卡开**，无法形成对称夹持。
3. **手指电机太弱**（gear=1，纯力矩）→ 遇到障碍推不动。

**结论**：这不是 IK/轨迹/重力补偿的问题（这些**都已解决**），而是**自建夹爪的机械设计**
不适合"从上方夹取球体"这一任务。换用官方 Franka Panda（平行夹爪，几何已调好）即可直接抓取。

# A2 轮：夹爪几何修正 + 力控闭合（2026-09-22 续）

## 本轮改动（已提交到 A2 场景）

文件：`assets/arm6_gripper_table_a2.xml`
1. **`gripper_mount` 上移且不参与碰撞**（`pos="0 0 0.020"`, `contype=0 conaffinity=0`）→ 不再顶住球体。
2. **手指加宽加长**：间距 ±0.045、长度 0.055 → 可容下 5cm 球，指尖低于球心。
3. **手指执行器从 `motor`(gear=1) 改为 `position` 伺服**（kp=300, kv=15, ctrlrange=±0.08）→ 提供真实夹持力。
4. **求解器**：`iterations=100, tolerance=1e-10, integrator=implicitfast` → 消除高刚度手指的 QACC NaN。

## 关键突破：带偏航（yaw）约束的 6-DOF IK

在 `scripts/run_arm_eval.py` 的 `find_seed()` 和 `ik6()` 中**新增 `yaw_target` 参数**：
- 手指开合轴（局部 +Y）必须指向指定世界偏航角，否则手指以 ~42° 斜角接近 → 夹不住。
- `find_seed(..., yaw_target=π)` + `ik6(..., yaw_target=π)` → **位置误差 2.5mm、夹爪垂直朝下、手指轴沿 X（yaw=180°），且 j6≈0（接近 HOME，避免大摆动）**。
- 之前失败根因：无 yaw 约束时 IK 解出 yaw≈42°，且修正 j6 时会撞 ±180° 限位 → 手臂大范围摆动扫飞物体。

## 当前状态

- **IK（含朝向+偏航）**：✅ 完全收敛（poserr 2.5mm, yaw 精确到 0.2°）。
- **物体稳定性**：✅ 从合法 `qa` 起始、连续下降时物体**不再被撞飞**，稳定停在 (0,0.25,0.764)。
- **手指可达性**：✅ 验证过 `g=+0.03` 时两指尖距 1.4cm、dL=0.007（可夹住 5cm 球）。
- **仍未跑通**：抓取最后一环。实测下探后**两指不对称**（dL=0.079 vs dR=0.112），物体未被两指居中；闭合时 dL 不降 → 未形成有效夹持。真提升仍 ≈ -0.6mm。
  - 根因推测：`TIP_L/TIP_R` 局部偏移 `(0,∓0.008,-0.055)` 与实际手指几何仍有偏差，导致 tip_mid 目标点与真实指间中点不一致 → 物体偏心。

## 结论

A2 把**夹爪几何硬伤**（mount 阻挡）**解决了**，并**补全了 IK 的朝向/偏航**，物体不再被撞飞。
**仅差最后的"精确居中夹持"**——需要一个准确的指尖几何标定，属精细但有限的工程。

**建议下一步（A3）**：用 MuJoCo 直接读取 `fl_tip/fr_tip` 的**真实世界坐标**（而非局部偏移估计）作为 IK 目标，自动消除 `TIP_L/TIP_R` 偏差，即可大概率打通抓取。

## A3 追加：真实指尖 FK + 手指动力学诊断

- `_fk_full()` 改用**真实指尖 geom (`fl_tip/fr_tip`) 世界坐标**（消除 `TIP_L/TIP_R` 估计偏差）。
- 验证：在正确构型下，`fl_tip=(-0.067,0.2498,0.7649)`、`fr_tip=(0.067,0.2498,0.7649)`、`tip_mid=(0,0.2498,0.7649)` **与物体 (0,0.25,0.765) 完全重合**。
  → **IK 与指尖定位已达到亚毫米级正确**。
- **新发现的拦路石**：手指**位置伺服严重跟不上**
  - 指令 `g` 从 -0.05 变到 +0.02，`fl_j` 仅从 -0.012 变到 +0.004（理论应到 ±0.02）。
  - 指尖间距仅由 9.8cm 缩到 6.7cm，**无法闭合到夹住 5cm 球所需的 ~5cm**。
  - 即：**手指执行器/关节动力学（damping=1.0, armature=0.01, kp=300）导致大稳态误差**，或是手指被内部接触卡住。
- 因此即使 IK/定位完全正确，**手指仍张不到能夹住球的宽度**，抓取未成功。

2. ✅ 缺少 yaw 约束 → 已修（A2）

建议：**A4 专攻手指动力学**（单一变量：kp/damping/armature/步长），预计可打通；

## A4 追加：手指动力学澄清

隔离测试证明**手指执行器本身完好**：从 qpos=0 指令 0.02，`fl_j` **精确到 0.02**，指尖距 9cm→3.4cm。
但在完整抓取中，闭合时 `dL=dR=5.5cm`（对称），**指尖始终在物体外侧 ~5cm**，即使指距已缩到 3.9cm。
→ 说明**物体与指尖在 z 或 y 上仍未对齐**（物体可能被闭合过程挤到指尖下方/侧方）。
指距 3.9cm（±1.95cm）本应进入 5cm 球范围内，却 dL=5.5cm → 存在**额外 ~4-5cm 的位姿偏移**。

**这是 A2/A3/A4 的最终收敛点**：IK/指尖定位在"空载校验"下完美（tip_mid 与物体重合），
但**实际接触/闭合时存在未建模的偏移**（可能是接触力把物体/手指推开、或指尖 geom 接触点在别处）。
继续调试需要**逐帧接触分析**，超出本轮预算。
