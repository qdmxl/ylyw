## 零、定位与核心主张

提出**基于《易经》六爻体系**的无监督工业图像异常检测框架。核心：把图像（或其深度特征）中的**异常响应**建模为"六爻传感器阵列"读数，以**爻变（变化）**哲学——而非统计正交距离——判异常。

**关键定位（据 (丙) 决策）**：
> **框架是「信号无关」的**——同一套六爻模型 + 爻变判据 + 在线学习，既可接**纯手工信号（零先验）**，也可接**ImageNet 预训练特征**。
> **性能上限由信号质量决定**：框架不产生知识，只**组织**知识。

**两条证据线（一篇论文内）**：
- **线 1 · 零先验**：纯手工六爻信号（残差/频域/结构张量/颜色…）→ 平均 AUROC ≈ 0.85，**完全可解释、无任何预训练**
- **线 2 · 借用视觉先验**：ImageNet 预训练 ResNet 多层特征作六爻读数 → L1+L3 融合 ≈ 0.93，与 PaDiM 同级

**三级递进证据链（证明"知识在信号里，不在框架里"）**：
```
随机卷积 (0.77)  ← 载体无知识
   < 手工固定卷积 (0.80)  ← 设计的知识填一部分
   < 纯手工六爻信号 (0.85)  ← 领域知识
   < ImageNet 预训练 (0.93)  ← 学习到的知识填得最满
```

### 贡献列表
1. **六爻传感器模型**：把任意"异常响应场"映射为 6 维**可解释**读数（信号无关）
2. **爻变判据**：以**爻间关联结构的变化**判异常，**明确否定正交化**（附负结果）
3. **自适应阈值 + 在线学习**：参数自由（q=75）、Welford 增量、冷启动鲁棒
4. **信号无关性实证**：同一框架在手工信号与预训练特征上均有效；并给出"知识来自信号而非框架"的消融证据链
5. **数据效率**：few-shot（10 样本 → 0.956）；可在线演进

## 二、各章详细框架

### Abstract 要点
- 缺口：工业 AD 依赖预训练特征 + 大量正常样本，边缘部署难、可解释性差
- 方法：六爻传感器阵列 + 爻变判据 + 在线自适应
- 结果：手工信号 0.85（零先验）；预训练信号 0.93（PaDiM 级）；few-shot 0.956
- 主张：**框架信号无关**；预训练消融证明"知识在信号里"

### 1. Introduction
- 1.1 工业质检背景，MVTec AD 为事实标准
- 1.2 现有方法两类（PaDiM 统计 / PatchCore memory bank）**都依赖 ImageNet 预训练**
- 1.3 缺口：**零先验、可解释、可在线**的方法缺位；且"预训练到底贡献了什么"缺乏干净的消融
- 1.4 贡献列表（见上）

### 2. Related Work
- 2.1 工业异常检测：PaDiM, PatchCore, SPADE, MVTec AD
- 2.2 手工特征 / 传统统计方法
- 2.3 在线 / 增量无监督学习；无预训练特征方法
- 2.4 易理与现代计算交叉（哲学基础）

### 3. Theoretical Framework ★核心（只讲一次）
- 3.1 **六爻传感器模型**：6 个传感器的定义（初爻…上爻）
- 3.2 **爻变判据（关键）**
  - **否定正交性**：爻间相关性 = 信息，非冗余
  - 异常 = 爻读数偏离正常分布 **且** 爻间关联结构被破坏
  - 与 PCA/whitening 对比（负结果，见 §6）
- 3.3 **自适应阈值**：正常分数分位数 q=75（参数自由）
- 3.4 **在线学习**：Welford 增量均值/方差/协方差；1/n 权重衰减 = 天然遗忘

### 4. Method（信号无关的框架 + 两条信号实例）
- 4.1 通用流程：信号 → 残差场 R = |F−T|/SD → 六爻读数 → 分数 → 阈值
- 4.2 **六爻算子定义**（初=残差峰值，二=FFT 高频比，三=结构张量各向异性，四=|R−mean|max/std，五=颜色残差，六=高对比连通域密度）
- 4.3 **信号实例 1（零先验）**：手工特征构造
- 4.4 **信号实例 2（视觉先验）**：ResNet18(IMAGENET1K_V1) layer1/2/3 → 多层六爻传感器；**冻结、无微调、无目标域标注**
- 4.5 **多层融合**：L1（/4，抓局部）+ L3（/16，抓形状）互补；L1+L3 最佳
- 4.6 **在线引擎**：从首样本开始 Welford 学习；自适应阈值；冷启动鲁棒
- 4.7 可选 kNN 增强（对照）
- 4.8 复杂度与边缘友好性

### 5. Experiments
- 5.1 数据集：**MVTec AD（15 类）** ← 数据补全中
- 5.2 指标：image-level AUROC（主）+ accuracy
- 5.3 协议：仅 train/good 学习；只 test 评估
- 5.4 **主结果表**：含 0.77/0.80/0.85/0.93/0.964/PaDiM/PatchCore
- 5.5 **信号无关性分析**：同一框架、不同信号（呼应三级证据链）
- 5.6 层贡献 / 分辨率（/4 vs /8）/ 在线 vs 冻结
- 5.7 few-shot 曲线

### 6. Ablation & Analysis（负结果集合 —— 方法论亮点）
- 6.1 **预训练消融**（核心）：预训练 ResNet(0.93) vs 随机 ResNet(0.77) vs 手工固定卷积(0.80) → "知识在信号里"
- 6.2 爻变 vs 爻正交（负结果）
- 6.3 PCA whitening（负结果）
- 6.4 敏感爻自动学习（负结果：正常方差无法识别敏感度）
- 6.5 自适应层加权（负结果：权重退化为均匀）
- 6.6 阈值规则扫描 → q=75 依据
- 6.7 冷启动污染实验（首 N 个缺陷样本影响极小；Welford 天然遗忘）
- 6.8 收缩协方差 / 多尺度 / top-hat（负结果）

### 7. Discussion
- 7.1 易理视角：**"变化"是异常的本质**；相关性即信息
- 7.2 **知识与载体之辨**：卷积是空载体；框架只组织知识，不产生知识
- 7.3 负结果的价值：无监督下"敏感度"不可从正常数据统计量推断
- 7.4 局限：预训练信号非真·零先验；metal_nut 细划痕仍是短板

### 8. Conclusion
