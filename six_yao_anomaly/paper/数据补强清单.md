## 优先级 1（必做）：VisA

| 项 | 内容 |
|---|---|
| 数据集 | **VisA**（Visual Anomaly Detection） |
| 来源 | https://github.com/amazon-science/spot-diff |
| 规模 | 12 类，10821 图，9623 正常 / 1200 异常 |
| 为什么 | 与 MVTec 并列的工业异常检测标准数据集，审稿人最认 |
| 产出 | 逐类 AUROC 表 + 平均；与 MVTec 结果并排 |

**做法**：
1. 下载 VisA（注意申请/下载方式，见仓库 README）；
2. 写一个 loader，接口对齐 `exp31_full15.py` 里的 `load_split(cat, split)`，
   返回 `(图片路径, 标签0/1)`；
3. 跑 5 个变体：手工 / L1 / L2 / L3 / L1+L3；
4. 结果存 `results/exp34_visa_*.json`。

⚠️ VisA 目录结构与 MVTec 不同（是 `split_csv` + `images/`），需要适配。
   注意 VisA 的 "multi-class" 与 "single-class" 协议，统一用 single-class 与本文可比。

## 数据相关工程注意

1. **目录结构统一**：建议把新数据集也放到 `data/`，写好 loader 后与
   `data/mvtec_full` 并列。
2. **磁盘**：MXL 盘现剩 **23G**（97% 已用）。VisA 约 2–3G，MPDD/BTAD 各几百 MB，
   够用；下载前先确认余量。
3. **内存**：沿用"Welford 增量 + float32 + 逐类清零"，3–4GB 机器可跑。
4. **可复现**：随机种子固定；每个数据集的 loader 单独成文件，便于复查。
