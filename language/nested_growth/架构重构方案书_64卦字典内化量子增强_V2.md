## 零、为什么必须重构（马老师五条判断的凝练）

昨天的工作（08-21）已证明：**现有引擎在八卦坐标下语义是健康的**（A1 判别 31.7%≈2.5×随机、
6卦消融Δ全负）。但它是一个 **8 卦标签 + 静态部首查表 + 简单嵌套繁殖** 的系统，能力天花板清晰。

马老师今天指出五个根因，全部成立：

1. **分辨率不足**：8 卦对海量汉字/词句不够 → 须用 **64 卦**（=6爻全排列 2⁶=64）实现精准区分。
2. **语义来源单一**：只在"字形构造"上匹配八卦，而大量字词是人类意识的自组织产物，
   不直接对应自然万象 → 不能只从字形带语义，要建模语言系统内部的**关系网络自组织规律**。
3. **放弃人类知识**：人学语言靠字典/词典/说文解字，引擎却零样本自己摸索 →
   必须**学习字典词典**，这才是汉语丰富语义的真正来源。
4. **知识要内化而非检索**：不是建知识库做检索（RAG），而要**内化为模型内部结构**，
   让汉字之间的丰富联系长在参数/状态里。随小说、医典大量阅读持续内化，理解不断丰富。
5. **量子易理 + 自生成 + 自学习**：重构底层架构为：
   - 基底 = **64卦**（6-qubit 全空间）
   - 具备 **自生成**（字胞→词胞→句胞→篇章 嵌套生长）
   - 具备 **自学习修正内部参数**（知识内化）
   - 利用 **64卦系统内部的丰富联系与转换规律** 学习汉字系统内部自组织规律
   - 真正实现 **类人脑的汉语语义理解学习模型**

### 设计原则（比照昨天的方法学军规）
- **理解 ≠ 聚类退化**：不把语义理解为"归到某个单点标签"，而是保持结构化分布。
- **知识内化 ≠ 检索**：字典先验注入为**可学习的模型初始状态/参数正则**，不是检索库。
- **不追评测数字、不过拟合**：诚实报告机制净效果，戒调阈值。
- **量子增强 ≠ 全量子**：经典承载大规模自学习内化，量子做高维语义启发与增强。
  当前为 NISQ，无端到端大规模量子训练；量子是"语义空间的结构引擎"，经典是"记忆与学习引擎"。

## 二、设计决策逐条展开

### D1. 64卦基底：从 8 标签 → 64 全空间（回应判断1）

**现状**：`YAO_BY_BAGUA` 只定义 8 个卦的 6 位向量，`word_sem_yao` 把词归到 8 卦之一。
**问题**：8 卦只有 8 个语义槽位，上万汉字必然大量坍缩进同一槽。

**重构**：
- **64卦 = 6 位的全部 2⁶=64 种排列**（第 0~63，十进制 index 即"卦序"）。
- 8 卦只是其中 8 个"尖峰原型"（乾=111111=63、坤=000000=0、离=101101 等）。
- **每一个汉字/词映射到一个 64 维概率分布**（soft vector over 64 卦），而非 8 选 1。
  → 分辨率从 8 提升到 64，且可表达"半巽半离"的中间态。
- 6-qubit 量子实现：64 维复态向量 `|ψ⟩∈ℂ^64`，每个计算基态 `|index⟩` = 一个卦。
- **组合编码**：单字→卦分布；多字词→字分布的张量/纠缠组合；句→词态合成。避免"一字一卦"的静态映射（64 仍不够上万字，须组合）。

### D2. 字典/说文解字先验内化（回应判断3、4）★本次核心新增

**原则**：字典是"浓缩的汉语知识"，必须以**先验**形式注入模型内部结构，而非做成检索库。

**先验来源**（分优先级）：
1. 《说文解字》：部首+本义 → 字的**字源语义卦分布**（先天字形先验，已有部首通道，扩充到 64 卦）。
2. 现代汉语词典：词的**义项列表** → 词胞初始 `sem_yaos`（多义先验，而非从语料零起步学）。
3. 词性/用法/搭配（词典标注）→ 词胞的**语法角色先验**（虚词、句法功能，回应"语言自组织规律"）。

**内化方式**（三层）：
- **初始化**：字/词胞一诞生，其 64卦分布/义项库直接用字典先验初始化（不随机、不零样本）。
- **正则**：学习时字典先验作为**强先验**，防止语义漂移（镜像 08-21 的"基础义保护"思想，升级为"字典义保护"）。
- **持续内化**：模型从语料（小说/医典）学习时，新知识**收敛进既有字典义项或新增义项**，
  与字典知识融合，而非覆盖。→ 随阅读量增大，字典知识被应用、被丰富。

### D3. 语言自组织规律的学习（回应判断2）★纠正单一只靠字形

**问题（判断2精确表述）**：汉字系统里有很多字是**为反映语言系统内部自组织规律**而存在，
不与自然万象一一对应（语法助词、构词法、语音演化、虚化义、抽象逻辑词）。
**纠正**：不能只在"字形构造 ↔ 八卦"上匹配。

**方案**：让模型从**字/词在语料中的共现与搭配关系**中学习语言系统的自组织规律，
并把这种"关系网络"内化为词胞之间的联系结构（卦间转移/呼应），而非仅靠字形。
- 字形通道（先天）→ 自然范畴先验
- 语料共现通道（后天）→ 语言自组织规律（虚词、搭配、语法）
- 双通道融合进 64 卦分布（呼应设计文档 §结果③"先天字形+后天语料互补"）

### D4. 量子增强：64卦全空间的语义动力学（回应判断5）

把 08-21 已验证的量子同构**从 8 卦原型扩展到完整 64 卦全空间**：

| 经典/易理 | 量子 6-qubit(64维) |
|---|---|
| 字胞/词胞 64卦分布 | 叠加态 `\|词⟩=Σ_i α_i\|i⟩`（64卦权重） |
| 多义（词包多义项） | 叠加态天然容纳（不坍缩） |
| 词-词关联(自组织) | 纠缠 / 张量积 |
| 语境择义 | 测量（投影，调概率不毁结构） |
| 六爻变/卦变(转换规律) | 酉变换/态演化 |
| H 自学习 | 变分量子电路(VQC) 参数化 |

**经典-量子分工**（务实，NISQ）：
- **经典层**：承载大规模语料的自学习与知识内化（这是当前真正能做的语义能力来源）。
- **量子层**：作为**高维语义空间增强引擎**——负责多义叠加表达、词间纠缠关联、语境测量择义、
  卦间转换；不负责端到端大模型训练。
- 接口：经典算出的 64卦分布 → 编码为量子叠加态 → 量子层做增强(纠缠/测量/演化) →
  测量结果回喂经典层继续学习。

### D5. 自生成与自学习（保持并强化 08-21 成果）

- **自生成**：保留 `ensure_char_cells → ensure_word_cell → process_sentence_words` 三级嵌套，
  升级为 64 卦语义。字胞(仓库)→词胞(仓库/消歧)→句胞(聚合)→(新增)篇章胞。
- **自学习修正内部参数**：保留 `commit_game`/`H` 参数校准 + 分布学习；
  新增"字典正则"防止学偏。
- **知识内化闭环**：读语料 → 观察新语义 → 收敛/新增义项 → 沉淀进词胞/模型参数。

| 原机制 (08-21) | 新架构 | 关系 |
|---|---|---|
| 8 卦标签 YAO_BY_BAGUA | 64 卦全空间分布 | 扩维（8=64 的子集原型） |
| word_sem_yao 静态查表 | 字典先验初始化 + 内化 | 增强（先验从字形扩到字典） |
| 8维部首语义 | 64卦 + 字典义项 | 扩充 |

| 经典 float 六爻 | 量子 6-qubit 64维态 + 经典双轨 | 增强 |

**演进顺序**（不推翻，逐步升级）：
1. **先经典落地**：64卦软分布编码 + 字典先验内化 + 双通道(字形+语料) —— 这是当前可做、能力提升最实的一步。
2. **再量子增强**：把 64卦分布的经典结果接向量子叠加/纠缠/测量层，复用 08-21 已验证的抗坍缩结构优势。
3. **固化论文**：对齐"卦象语义与量子同构"章节，新增"64卦全空间 + 字典先验内化"论证。

## 五、预期收益与诚实边界

**预期收益**（基于昨天证据的合理外推）：
- 判别分辨率：8→64 槽位，减少语义坍缩（昨天已证 8卦下 31.7% 且无死锁，64 卦应更精细）。
- 多义表达：字典义项先验 + 量子叠加 → 不再"零样本硬切"，更接近人"学过词典再读小说"。
- 知识内化：字典+语料双通道 → 比"纯字形"语义来源丰富得多（回应判断2/3/4）。

**诚实边界**：
- 64 卦仍远小于上万汉字 → 必须依赖**组合/分布编码**，不能"一字一卦"（写死这一点，防犯老错）。
- 量子层面受 NISQ 限制，做增强不做全量子训练。
- 字典数据规模：先抽样验证机制，不全量手工录入；后续可对接开源词典语料。
- 评测不造假：机制净效果为主证据，不调阈值追数字。
